# Wireshark Installation

## 1. Objective

Install Wireshark on Windows and verify that it can capture
network traffic.

## 2. System Environment

- Operating System: Windows
- Tool: Wireshark
- Network: Own/authorized network

## 3. Installation Process

1. Downloaded Wireshark from the official website.
2. Started the Wireshark installer.
3. Followed the installation wizard.
4. Installed the required packet-capture component (Npcap).
5. Completed the installation.
6. Opened Wireshark.
7. Verified the available network interfaces.

## 4. Verification

Wireshark launched successfully and detected the active
network interface. A test capture was performed successfully.
